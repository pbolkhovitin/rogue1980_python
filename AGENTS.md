# Rogue 1980 Python Project

Ты — агент разработки (opencode). Задача — реализовать игру Rogue 1980 на Python 3.10 с библиотекой curses.

**ВАЖНО: Отвечай всегда на русском языке, включая технические комментарии и рассуждения.**

## Проект
- **Название**: Rogue 1980 Clone
- **Язык**: Python 3.10
- **Интерфейс**: curses (консольный)
- **Архитектура**: Чистая архитектура (domain/presentation/data)

## Правила разработки

### Архитектура
- Строгое разделение слоёв: `domain` НЕ импортирует `presentation` и `data`
- Dependency injection для связи слоёв
- Состояние хранить в объектах (GameSession, Level, Player), избегать глобальных переменных

### Кодстайл
- Модульность: максимум 300 строк на файл
- Типизация: все аргументы аннотированы, использовать `from __future__ import annotations`
- Именование: `snake_case` для функций, `PascalCase` для классов
- Документация: docstring у каждого публичного метода

### Тесты
- Фреймворк: pytest
- Покрытие критических путей >80%
- Тесты на: сущности, генерацию, бой, AI, сохранение

### Коммиты
- Ветка: `develop` (не `master`)
- Формат: `[этап N] краткое описание`
- Перед коммитом: `pytest`, `mypy` и `ruff` должны проходить

## Игровые требования (MVP, Задания 0-5)

### Уровни
- 21 уровень, каждый — 9 комнат + коридоры
- Стартовая комната (без врагов), конечная (лестница)
- Сложность растёт с уровнем

### Персонаж
- hp, max_hp, dex, str, weapon (может быть None)
- Рюкзак: food/potions/scrolls/weapons (макс 9 каждого), treasure (число)

### Враги (5 видов)
- Зомби (z) — высокое hp, средняя сила
- Вампир (v) — крадёт max_hp, первый удар всегда промах
- Привидение (g) — телепортируется, становится невидимым
- Огр (O) — ходит на 2 клетки, отдыхает после атаки
- Змей-маг (s) — ходит по диагонали, может усыпить

### Предметы
- Еда (j) — восстанавливает hp
- Эликсиры (k) — временно повышают статы
- Свитки (e) — постоянно повышают статы
- Оружие (h) — бонус к силе

### Бой
- Пошагово: ход игрока → все враги действуют
- Проверка попадания (формула от dex)
- Урон от силы + оружие
- При победе — сокровища

### Управление
- WASD — движение
- h/j/k/e — использование предметов
- 1-9 — выбор предмета из списка
- 0 (для оружия) — снять текущее оружие

### Рендеринг (curses)
- Стены, пол, персонаж, враги, предметы
- Туман войны + ray casting
- Статусная панель (hp, str, dex, уровень, сокровища)
- Меню, инвентарь, таблица рекордов

### Сохранение (JSON)
- После каждого уровня — полное сохранение
- Загрузка последней сессии при старте
- Таблица рекордов всех попыток

## Формулы расчёта (для reference)

### Попадание (hit)
chance = 0.5 + (attacker_dex - target_dex) / 20
chance = max(0.1, min(0.9, chance))
hit = random.random() < chance

### Урон (damage)
base_damage = random.randint(1, attacker_str + weapon_bonus)
weapon_bonus = оружие.equipped.bonus если есть, иначе 0


### Сложность (с ростом уровня)
```python
enemy_count = base_count + level // 3
enemy_hp_multiplier = 1 + (level - 1) * 0.1
item_quality_factor = max(0.3, 1.0 - (level - 1) * 0.05)
```
